# Iron Tide 4 — PFT Companion

12-week USCG PFT training companion with cloud login: users sign up with an
email address and their workout checkmarks stay saved when they log back in.

## Plan

- Frontend: static site (deploy to Vercel / Netlify / Cloudflare Pages)
- Auth + database: Supabase (email login, per-user progress in Postgres)
- Contents: 12 weeks, 72 sessions, 216 tasks, stopwatch, PFT target
  calculator and scoring tables, readiness log, test-day plan
